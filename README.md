# Austin & Jordyn: The Poradas Wedding Website

Welcome to the digital archive of Austin and Jordyn's wedding. This project is a custom-built, interactive web application designed to share our story, host our wedding gallery, and preserve the memories of our celebration.

## 🌟 Project Purpose

Originally built as a wedding invitation and information hub, this site has been transitioned into a **Post-Wedding Archive**. It serves as a permanent home for:
- Our engagement story and photos.
- A comprehensive wedding photo and video gallery.
- A digital guestbook for friends and family.
- An interactive map of our celebration.

## 🛠️ Technology Stack

- **Frontend**: React (TypeScript), Vite
- **Styling**: Vanilla CSS with custom design tokens
- **Animations**: Framer Motion, Anime.js
- **Backend & Database**: Supabase (Auth, Postgres, Storage, Edge Functions)
- **Deployment**: Netlify
- **Testing**: Vitest, Playwright

## 📂 Project Structure

- `src/components`: UI components organized by section and feature.
- `src/data`: Static project data and text content (Engagement story, etc.).
- `src/services`: Integration logic for Supabase and other external APIs.
- `supabase/`: Database schema, migrations, and edge functions.
- `scripts/`: Utility scripts for data import/export and site verification.
