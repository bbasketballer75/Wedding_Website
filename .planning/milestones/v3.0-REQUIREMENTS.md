## Category: Social Features (SOC)

### SOC-01: Activity Feed Page — ✅ VALIDATED

- [x] Activity feed page renders at `/activity`
- [x] Shows approved guest uploads in chronological order
- [x] Shows guestbook messages in chronological order
- [x] Pagination works (infinite scroll with 20 items/page)
- [x] Empty state displays when no activity exists

### SOC-02: Activity Feed Realtime Updates — ✅ VALIDATED

- [x] New guest upload appears in feed via Supabase Realtime
- [x] "New activity" banner appears when new items arrive
- [x] No duplicate entries or memory leaks on unmount

### SOC-03: Activity Feed Filtering — ✅ VALIDATED

- [x] Filter buttons render above feed (All | Photos | Guestbook | Moments)
- [x] Client-side filtering works
- [x] Active filter persists to sessionStorage
- [x] Active filter visually indicated (gold background)

---

## Category: Lightbox Enhancement (LB)

### LB-01: Pinch-to-Zoom on Mobile — ✅ VALIDATED

- [x] Pinch gesture on mobile zooms photo in lightbox
- [x] Zoom range is 1x to 3x
- [x] Double-tap toggles between 1x and 2x
- [x] Zoom resets when swiping to next/previous photo

### LB-02: Swipe Navigation Refinement — ✅ VALIDATED

- [x] Swipe left navigates to next photo
- [x] Swipe right navigates to previous photo
- [x] At first/last photo, swipe in that direction does nothing
- [x] When zoomed > 1x, swipe pans instead of navigating

### LB-03: EXIF Display in Lightbox — ✅ VALIDATED

- [x] Info panel shows "Date taken" from EXIF or fallback
- [x] Info panel shows "Camera" (camera model, lens, aperture, shutter, ISO) if metadata available
- [x] Graceful fallback when EXIF is unavailable

### LB-04: Download Button in Lightbox — ✅ VALIDATED

- [x] Download button visible in lightbox toolbar
- [x] Clicking downloads current photo at high quality
- [x] Filename is descriptive (photo ID + extension)

## Category: Download Management (DL)

### DL-01: Multi-Select Download Queue — ✅ VALIDATED

- [x] Long-press (mobile) or checkbox (desktop) selects multiple photos
- [x] Selected count shown in header during select mode
- [x] "Add to Download" button appears with selection
- [x] Queue panel accessible via FAB and shows selected items
- [x] Can remove individual items from queue

### DL-02: Batch Download with Progress — ✅ VALIDATED

- [x] "Download All" generates zip file (JSZip ≤20, Edge Function >20)
- [x] Progress indicator shows during preparation
- [x] Browser download triggers with correct zip file
- [x] Files named descriptively in zip

### DL-03: Download Queue Persistence — ✅ VALIDATED

- [x] Page reload preserves download queue (sessionStorage)
- [x] Queue badge shows count of items
- [x] Can continue adding to queue after reload

## Category: Self-Service (SC)

### SC-01: Photo Claiming via Email — ✅ VALIDATED

- [x] "Claim My Photos" button visible on Guest Uploads page
- [x] Email entry shows matching uploads (if any)
- [x] Magic Link email sent for verification (Supabase signInWithOtp)
- [x] 6-digit code verification with rate limiting (3 attempts, 10-min expiry)
- [x] After verification, photos linked to guest identity
- [x] Guest can view "Photos of me" collection via My Photos filter

### SC-02: Photo Claiming via Face Clusters — ⚠ DEFERRED

- [ ] Face cluster shows "Claim these photos" option
- [ ] Claim request appears in admin moderation
- [ ] Admin approves/rejects claim
- [ ] Approved claim links guest to face cluster
- [ ] Guest name appears on tagged photos

**Deferred reason:** SC-02 face cluster claiming deferred to post-launch per Phase 18 decision (D-16). Email-based claiming (SC-01) is functional.

### SC-03: Shared Album Links — ✅ VALIDATED

- [x] Share button generates unique UUID token
- [x] `/guest/:token` page renders guest's uploads and guestbook entries
- [x] Page is public (no login required)
- [x] Invalid/expired token shows friendly error
