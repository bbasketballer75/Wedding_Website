## Activity Card Component

Based on GuestHighlightReel pattern (D-01, D-02, D-03 from CONTEXT.md):

```
┌─────────────────────────────────────────────────┐
│ ┌──────┐  Name · "shared a photo" · 2h ago      │
│ │ img  │  [type icon: Camera]                   │
│ └──────┘                                        │
└─────────────────────────────────────────────────┘
```

- Thumbnail: 64x64px, rounded-xl (1rem), object-cover, left-aligned
- Card background: cream-100 to white gradient (from D-02)
- Entry: type icon (Camera/MessageCircle/Star from lucide-react)
- Timestamp: relative format ("2h ago", "Yesterday", "Mar 15")
- Layout: flex row, gap-md

---

## Filter Bar Component

Filter toggles (D-12 from CONTEXT.md): All | Photos | Guestbook | Moments

```
[All] [Photos] [Guestbook] [Moments]
```

- Active state: gold-500 text + bottom border (2px gold-500)
- Inactive state: charcoal-400 text
- Transition: 300ms color change
- Persist active filter to sessionStorage (D-13)

---

## New Activity Banner

"D-05: Click prepends new items to top without scrolling"

```
┌─────────────────────────────────────────────────┐
│ ↑ 5 new activity — click to load               │
└─────────────────────────────────────────────────┘
```

- Background: gold-500 at 10% opacity
- Text: gold-600
- Icon: ArrowUp from lucide-react
- Position: fixed top of feed, below header
- Click: prepends items, dismisses banner

---

## Feed Layout

- Container: max-w-2xl centered
- Stack: flex-col, gap-md between cards
- Pagination: "Load more" button at bottom (20 items per page)
- Auto-infinite scroll triggers at 200px from bottom (D-07)
- Scroll position maintained on prepend
