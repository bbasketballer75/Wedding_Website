<objective>
Standardize border radius across UI components per D-01 (two-tier system) and D-02 (no rounded-3xl as standard).

**D-01:** Tier 1 (`rounded-xl`) for buttons, inputs, small elements; Tier 2 (`rounded-2xl`) for cards, modals, feature panels.
**D-02:** No `rounded-3xl` as standard tier — use `rounded-2xl` for large decorative containers.

*Preserve `rounded-full` for pills, avatars, badges — these are intentional.*
</objective>

```typescript
export const components = {
  button: { radius: '9999px' },   // rounded-full (pills)
```

From index.css (Tailwind v4 built-in radius utilities):
- `rounded-xl` = 0.75rem (12px) — buttons, inputs, small
- `rounded-2xl` = 1rem (16px) — cards, modals, panels
- `rounded-full` = 9999px — pills, avatars, badges

D-01 mapping:
| Element Type | Target | Exceptions |
|-------------|--------|------------|
| Buttons | `rounded-xl` | pill buttons → `rounded-full` |
| Inputs | `rounded-xl` | search inputs with full radius → keep |
| Cards | `rounded-2xl` | none |
| Modals | `rounded-2xl` | none |
| Large decorative | `rounded-2xl` | per D-02 (was rounded-3xl) |
| Pills/badges/avatars | `rounded-full` | keep — intentional |
