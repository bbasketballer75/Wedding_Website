# Wedding Website

Read [AGENTS.md](AGENTS.md) for the setup, architecture, security and release gates. Use [CLAUDE.md](CLAUDE.md) for deeper architecture if needed; resolve discrepancies against package.json and CI.

- Use the npm lockfile and the package.json toolchain declaration. Start with npm run dev. For local CI parity, run npm run lint, npm run format:check, npx tsc --noEmit, npm run test:run and npm run build.
- For UI changes, test the affected local public flows. Treat npm run verify:release as a distinct gate with its documented prerequisites; do not substitute a local build for production readiness.
- Keep private event and media content out of diagnostics, fixtures and public previews. Do not run publication, upload or production database scripts as part of a local review.
