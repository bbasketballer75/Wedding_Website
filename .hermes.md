# Project Overview

Purpose: Wedding Website interactive web application
Primary language: JavaScript / React / HTML / CSS
Package manager: npm

## Important Paths

- Source: src/ or public/
- Configuration: package.json

## Required Commands

Install: npm install
Build: npm run build
Test: npm test
Development server: npm start / npm run dev

## Coding Rules

- Preserve responsive design and interactive animations.
- Check diff before completion.
