**Failure analysis (routed, not hidden):**
1. **Gallery mobile** — pagination timing under the capture's window scroll: frozen oracle ends with 30 images / 11156 px, rebuild with 24 / 9528 px + `LOAD MORE`. All other mobile gallery aspects (text, ordering, tile layout, ratios) match; desktop both themes pass at 0.0137%. Root cause: the virtualized fixed-height capture windows do not trigger one extra `loadMore()` on the rebuild the way the frozen scroll handler does. Tracked as a Wave-9 follow-up (not product copy/layout).
2. **Admin mobile** — pixel-only (8.07% dark / 2.72% light), no DOM/text difference, heights 3446 vs 3415: mobile admin shell/card theme tokens differ from the frozen light-card treatment below `xl`. Desktop both themes match byte-for-byte (0.0000%). Tracked as a Wave-9 mobile chrome follow-up.
