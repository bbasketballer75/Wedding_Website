## 5. Deviations from the approved plan (all deliberate, all reviewed)

1. **No new npm dependencies.** The plan proposed `pixelmatch` + `pngjs`; the harness uses the
   already-installed `sharp` for PNG decode/encode and RGB diffing instead. `package.json` gained
   scripts only.
2. **Freeze exception.** One migration file was repaired (four missing semicolons) so the schema
   baseline can be reproduced; it never enters the client bundle. Documented in the checker and A3.
3. **Sandbox Supabase.** Port collision with another local project forced a `--workdir` sandbox with
   shifted ports; migrations themselves are unmodified.
4. **Freeze checker semantics.** It audits branch-only diffs vs the merge base with `origin/main`
   (not "everything since the tag"), so upstream commits cannot fail the branch spuriously.
5. **Parity determinism** needed more than `page.clock.setFixedTime`: the harness warms the context,
   pauses the clock, then captures; a documented mask list handles genuinely animated widgets.

## 8. Return on the rebuild (what "improve overall" is worth, measured)

- 27.3% of the source tree is dead and can simply not be ported.
- ~17 unused/phantom dependency problems can be cleared instead of inherited.
- The performance problem is identified as **media loading/pagination**, not framework render, so
  budgeted image/video delivery is the highest-value fix.
- SEO is a share-preview problem already solved by one edge function; the rebuild adds a real
  static OG image rather than importing an SSR framework.
- The rebuild will be held to `docs/rebuild/QUALITY_BAR.md` (strict TS, type-aware lint, coverage
  thresholds, bundle/LCP budgets, axe gates, contract tests) — all things the frozen app lacks.
