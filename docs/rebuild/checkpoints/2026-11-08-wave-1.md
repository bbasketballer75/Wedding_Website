## Findings that matter

1. **The frozen body font is a fallback, not the token.** Frozen `index.html` inline critical CSS is
   unlayered (`body{font-family:'Inter',sans-serif}`), so despite the `--font-body` token being
   Instrument Sans, body copy renders in the generic sans-serif fallback (Inter is never loaded).
   The rebuild reproduces this exactly; switching to Instrument Sans would be a visual change and
   needs an owner decision (R25).
2. **Metadata parity needs the static head, not just dynamic meta.** The frozen head ships 20 static
   meta tags; the harness compares the whole map. `rebuild/index.html` now mirrors it and
   `usePageMeta` applies the full SEOHead set.
3. **Contract wording bug fixed:** `robots` values are `index, follow` / `noindex, nofollow` (with
   spaces). `contracts/seo-pwa.json` + schema corrected to the rendered truth.
4. **Harness can address non-navigable routes:** `not-found` captures `/people` via
   `ROUTE_PATH_OVERRIDES`; the captured URL is recorded in `summary.json`.
5. **ESLint 9 is end-of-life but required** by `eslint-plugin-jsx-a11y@6.10.2` (peer cap). Tracked
   as R24; the greenfield app is otherwise on current majors.
