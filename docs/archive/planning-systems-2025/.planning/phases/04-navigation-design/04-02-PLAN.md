## Gold Color Token Reference
- `gold-500` (#c9a05c): Primary gold for active/selected states, primary buttons
- `gold-600` (#a8874a): Darker gold for hover states on primary gold
- `gold-400` (#d4b483): Lighter gold for secondary elements, icons
- `gold-700` (#7a5c32): Dark gold for text on light backgrounds
- `gold-300` (#e8d5a3): Very light gold for dividers, borders

## Interactive Element Checklist

3. Active/selected states (background or border: gold-500)
4. Icon colors (gold-500 or gold-400)
5. Focus rings (gold-400 or gold-500)
