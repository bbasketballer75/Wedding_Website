## Reduced Motion Contract (UX-10)

**Decision:** CustomCursor returns `null` when `prefers-reduced-motion: reduce` is detected (D-01).

**Pattern:**
```tsx
const CustomCursor = () => {
  const [reducedMotion, setReducedMotion] = useState(false)

  useEffect(() => {
    const mediaQuery = window.matchMedia('(prefers-reduced-motion: reduce)')
    setReducedMotion(mediaQuery.matches)

    const handler = (e: MediaQueryListEvent) => setReducedMotion(e.matches)
    mediaQuery.addEventListener('change', handler)
    return () => mediaQuery.removeEventListener('change', handler)
  }, [])

  if (reducedMotion) return null

  // ... rest of cursor implementation
}
```

**No static fallback.** Users who prefer reduced motion get the system default cursor. No reduced animation mode — fully hidden (D-01).

## Animation Duration Baseline (UX-12)

**Decision:** DarkModeToggle animation stays at `duration: 0.3` (300ms) — already correct (D-04).

**Baseline durations for consistency:**
| Type | Duration | Usage |
|------|----------|-------|
| Micro-interactions | 150ms | Hover states, button presses |
| Transitions | 300ms | Theme toggle, modal open, page transitions |
| Animations | 500ms+ | Complex entrance/exit animations |

**DarkModeToggle:** `duration: 0.3, ease: [0.4, 0, 0.2, 1]` (easeInOut) — preserved per D-04.

## Aria-Label Pattern (UX-09)

**Decision:** Add `aria-label` to all interactive elements lacking descriptive text (D-05).

**Already compliant:**
- `DarkModeToggle.tsx` — has `aria-label="Toggle dark mode"` or similar

**Components requiring aria-label fixes:**

| Component | Element Type | aria-label needed |
|-----------|-------------|-------------------|
| `GalleryHeader.tsx` | Icon button (filter) | "Filter photos" |
| `GalleryHeader.tsx` | Icon button (sort) | "Sort photos" |
| `GalleryHeader.tsx` | Icon button (search) | "Search photos" |
| `Toast.tsx` | Icon button (close) | "Dismiss notification" |
| `PhotoItem.tsx` | Icon button (action) | "Photo options" or "More actions" |
| `BatchList.tsx` | Icon button (clear) | "Clear filter" |
| `Search.tsx` | Icon button (clear) | "Clear search" |

**Rule:** When an interactive element has no visible text label, it MUST have a descriptive `aria-label`. Icon-only buttons always need aria-label.
