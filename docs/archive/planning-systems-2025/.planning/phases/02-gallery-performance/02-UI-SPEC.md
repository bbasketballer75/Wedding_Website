## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, masonry column gap |

| lg | 24px | Section padding, control bar padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |

**Gallery-specific exceptions:**
- MasonryGrid column gap: 8px (gap-2)

## Progressive Loading & LQIP Contract

### Placeholder Visual Treatment
- **LQIP type:** Blur hash placeholder (Decision D-02 from 02-CONTEXT.md)
- **Blur effect:** 20px blur with scale(1.1) to hide blur edges
- **Base placeholder color:** bg-charcoal-200 (for images without blurDataURL)
- **Transition:** 300ms opacity fade from placeholder to full image

### Progressive Reveal Animation
- **Image fade-in:** 300ms duration, opacity 0 to opacity 100
- **Staggered grid entry:** delay = min(index * 0.04, 0.5) per item
- **Skeleton shimmer:** bg-cream-200 animate-pulse

### Lightbox Overlay
- **Backdrop:** bg-black/95 (fixed inset-0)
- **Close button area gradient:** bg-gradient-to-b from-black/55 to-transparent
- **Caption area gradient:** bg-gradient-to-t from-black/85 to-transparent
- **Image transition:** 220ms opacity (AnimatePresence mode="wait")

### Prefetch Contract
- **Strategy:** Aggressive prefetch (Decision D-03 from 02-CONTEXT.md)
- **Prefetch targets:** Both next AND previous images
- **Implementation:** Prefetch adjacent images while viewing current
