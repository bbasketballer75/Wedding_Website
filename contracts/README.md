# contracts/ — the rebuild's source of truth

The greenfield app is **not** allowed to read the legacy app's source. It reads this directory.
If a behavior, string, image, route, table, or header is not represented here, it does not exist
for the rebuild — and the parity harness will catch the omission.

## Rule of thumb

- **Structured data** (story, film chapters, photo collections, wedding config) → `content/*.json`
  extracted from the frozen legacy modules, reviewed by a human.
- **Rendered truth** (what a visitor actually reads/sees) → `content/rendered/<route>.json`,
  captured from the running frozen app.
- **Behavior** (routes, auth, fixtures) → `routes.json`, `features.json`, `fixtures/`.
- **Platform** (SEO, PWA, headers, media hosts, DB) → `seo-pwa.json`, `media/`, `schema/`.

## Files

| Path                                        | Generated by                                   | Consumed by                                  |
| ------------------------------------------- | ---------------------------------------------- | -------------------------------------------- |
| `routes.json`                               | `npm run inventory:capture` (reviewed)         | parity harness, rebuild router, sitemap      |
| `features.json`                             | audit + `npm run inventory:capture` (reviewed) | wave planning, parity gates, acceptance      |
| `ui.json`                                   | audit A4                                       | parity matrix, design tokens                 |
| `seo-pwa.json`                              | audit A4/A5                                    | rebuild metadata, headers, manifest, edge OG |
| `parity-allowlist.json`                     | parity-eng (reviewed, expiring)                | parity harness                               |
| `content/*.json`                            | `npm run content:extract`                      | rebuild content layer                        |
| `content/rendered/*.json`                   | `npm run content:copy`                         | text-parity checks                           |
| `content/MEDIA_MANIFEST.json`               | `npm run content:extract`                      | media wiring + no-media-loss check           |
| `fixtures/*.json`                           | contracts-eng (ported from e2e mocks)          | parity harness, rebuild tests                |
| `schema/*`                                  | `npm run supabase:*` + backend-eng             | rebuild data layer, cutover plan             |
| `media/INVENTORY.json`, `media/CONTRACT.md` | backend-eng                                    | media wiring, CDN contract                   |
| `baseline/metrics.json`                     | `npm run baseline:capture`                     | wave exit criteria                           |
| `docs/rebuild/audit/*`                      | audit agents                                   | stack decision + wave plans                  |

## Validation

`npm run workbench:verify` validates every file against `tools/lib/schemas.mjs`, then checks
cross-references (features → routes, sitemap → routes, themes → ui, allowlist → routes). Do not
hand-edit a file into a shape the schema does not accept: change the schema deliberately and say
why in the PR/commit.

## Field notes (2026-11-08)

- **`seo-pwa.json` → `routes[].robots`** (optional): records the rendered robots meta where the
  frozen app sets it explicitly (`SEOHead` `noIndex`). It exists so noindex on `/print`,
  `/admin/login`, `/guest/:token` and the catch-all 404 is a reviewed contract fact rather than
  folklore. Absent = the static `index.html` default (`index, follow`).
- **`ui.json.fixedNow`** (optional): the single deterministic capture instant
  (`2026-11-08T17:00:00.000Z`, 12:00 America/New_York) shared by the rendered-copy generator and
  the parity harness. Time-dependent copy (home anniversary countdown, footer year) is only
  comparable when every harness freezes this one value — read it from here, never hardcode a
  second instant.
- **`parity-allowlist.json` is owned and governed by parity-eng.** Every entry needs a reason and
  an `expiresAtWave` (verify-contracts rejects anything beyond the roadmap), and the route must be
  declared in `routes.json`; remove entries when their wave has passed.
- **`fixtures/adminSession.json` is pinned, not live:** `session.expires_at` derives from
  `ui.json.fixedNow` so the committed fixture is deterministic (see `fixtures/README.md`).

## Regeneration

All generated artifacts are deterministic. Re-running a generator on an unchanged frozen app must
produce byte-identical output; the checkpoint checks this with `git diff --exit-code`.
